# Game engine

# О проекте
Изначально я хотел создать движок для битв undertale, но узнав, что сразу создать движок undertale не получится, я решил создать этот фундаментальный движок игры.
Этот проект с открытым исходным кодом. Код движка можно улучшать. 

# Объекты
Все объекты - это unique_ptr (умный указатель). Есть несколько типов объектов: Entity (главный), Wall, Enemy, Bullet, Element (UI объект). Некоторые объекты наследуют от Entity, ведь имеют общую характеристику: позиция и размер.

# Entity
Главным классом представляется Entity.
Свойства Entity:
Позиция,
размер,
текстура (с ней проблемы).

гланвые методы, которые я бы выделил:
Move - перемещает объект.
GetRec - возращает данные об обьекте.
Render - рендерит обьектю.
